# 記事の要約から店の紹介文を書く（せんべろ記事からの追加分）

東京の飲み屋地図に、せんべろ系の記事で紹介された店を追加する。営業中かどうかと住所は確認済み。
あなたは担当の `IN` ファイル（JSON 配列。各要素に `id` と記事の抜粋 `text`、タグ `kw`、食べログの分類 `tl_cat` などがある）を読み、
店ごとに次の項目を日本語で書いて `OUT` に書き出す。

## 書く項目（記事に根拠がないものは null。推測・誇張・創作をしない）

| キー | 内容 |
|---|---|
| `catch` | 店を一言で表す見出し。全角10〜22字、体言止め（例「朝9時から飲める駅前の立ち飲み」） |
| `desc` | どんな店か2文（場所の目安・店の形・名物）。常体（〜だ・〜する）か体言止め |
| `talk` | 人と話しやすいか1文（カウンター、店主、常連、立ち飲みの距離など）。根拠が薄ければ「〜で、一人でも入りやすい」程度に控えめに |
| `tips` | 行くときの一言（現金のみ、混む時間、システムなど）。無ければ null |
| `social` | 話しやすさ 1〜5（5=極小・コの字・店主がつなぐ、4=立ち飲み・カウンター中心、3=相席もある、2=グループ中心、1=交流ほぼなし） |
| `solo` | 一人で入りやすさ 1〜5 |
| `menu` | 記事に出てくる名物と値段（最大5件）[{"n": "煮込み", "p": "300円"}]。値段は記事どおり「〜円」 |
| `price_note` | 価格の目安を1文（例「ドリンク300円台から、つまみ200円から。2,000円あれば十分」） |
| `tags` | 次の語彙から当てはまるもの: 朝飲み, 昼飲み, 深夜, 一人飲み歓迎, 常連と話せる, 店主と話せる, コの字カウンター, カウンターのみ, 相席, 行列店, 現金のみ, キャッシュオン, チャージなし, 日本酒, ホッピー, 焼きとん, もつ焼き, 焼き鳥, 串カツ, 刺身, おでん, 煮込み, クラフトビール, レモンサワー, ワイン, 昭和レトロ, ガード下, 高架下 |
| `kind` | 確認: `tachinomi`（立ち飲み）/ `kakuuchi`（酒屋の角打ち）/ `senbero`（着席の大衆酒場・居酒屋）/ `bar`（小さなバー・スナック）。IN の `kind` が違っていれば直す |

- 記事の文をそのまま長く写さない。自分の言葉で短くまとめる。値段は記事の時点のものなので、`price_note` の最後に「（記事の時点）」と書く。
- 記事が店の紹介になっていない（まとめ記事の一部など）場合も、分かる範囲で書く。何も分からなければ desc に「せんべろ記事で紹介された◯◯（業態）」とだけ書く。

## 出力（UTF-8 の JSON。キーは id）
```json
{"bero-1003": {"catch": "…", "desc": "…", "talk": "…", "tips": null, "social": 4, "solo": 4,
  "menu": [{"n": "…", "p": "…"}], "price_note": "…", "tags": ["…"], "kind": "tachinomi"}}
```
20件ごとに OUT を書き出す（作業が途中で止まっても成果が残るように）。最後に件数だけ1行で報告する。
