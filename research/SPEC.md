# 東京 飲み屋マップ リサーチ仕様（全エージェント共通）

今日は 2026-10-07。目的は「東京の飲み屋横丁・センベロ・立ち飲み・角打ち、特に人とコミュニケーションがとれる場所」を網羅した地図のデータ作り。
あなたは担当エリアの店・横丁を調べ、JSON 配列を指定パスに書き出す。

## 調べ方
- WebSearch / WebFetch を使う（未ロードなら ToolSearch で `select:WebSearch,WebFetch` を読み込む）。
- 公式サイト・公式SNS・食べログ・Retty・ぐるなび・Hot Pepper・自治体/商店街サイト・ニュース記事・個人ブログ（2024〜2026年）を照合する。
- **営業中であることを確認する**。2024年以降の情報（口コミ・記事・SNS投稿）で営業が確認できない、または閉店・移転・再開発で消滅したものは `status` を `"closed"` か `"uncertain"` にする（closed も記録してよい。地図上では「閉店」として扱う）。
  - 例: 再開発で消えた横丁（立石・武蔵小山・下北沢など）は要確認。
- 住所は **番地まで**（例: `東京都北区赤羽1-17-7`）。ジオコーディングに使うので正確に。ビル名・階もあれば `address_detail` に。
- 推測で埋めない。分からない項目は `null`。ただし住所・最寄駅・種別・説明はできる限り埋める。

## 選定基準
- 種別（kind）:
  - `yokocho` … 飲み屋横丁・飲食街・ガード下・高架下の飲み屋群（複数店の集まり）
  - `senbero` … 千円〜二千円で飲める大衆酒場（着席中心）
  - `tachinomi` … 立ち飲み屋
  - `kakuuchi` … 酒屋の角打ち
  - `bar` … 小さなカウンターバー・スナック・横丁内の個人店で、店主や他の客と話しやすい店
  - `social` … 交流そのものが売りの場所（ゲストハウス併設バー、日替わり店主/間借りバー、コミュニティバー、外国人と交流できるバー、一人客同士をつなぐ店など）。相席屋のような出会い目的の業態は除外。
- 「人とコミュニケーションがとれる」場所を厚めに。コの字カウンター、極小店、立ち飲み、店主が客同士をつなぐ店は優先。
- 有名店だけでなく、地元で愛される店も入れる。チェーンは発祥店・旗艦店など特色のある1〜2店まで。
- 担当エリアで **合計 25〜40 件**（横丁 5〜10 件程度 + 店舗）。横丁の中の名物店は個別エントリーにして `yokocho` に親横丁の `id` を入れる。

## 交流度 social（1〜5）
- 5: 仕組み自体が交流前提（極小店・コの字カウンターで自然に会話、店主が客をつなぐ、交流バー）
- 4: 立ち飲み・カウンター中心で常連や隣の客と話しやすい
- 3: 混雑時の相席などで隣と話すこともある
- 2: グループ客中心だが一人でも入れる
- 1: 交流はほぼない（安さ・味が目的）

## 一人飲みのしやすさ solo（1〜5）
同様に 5 が「一人客が大半・常連も一見も歓迎」、1 が「グループ向け」。

## 出力形式（UTF-8 JSON 配列、他の文字は書かない）
```json
[
  {
    "id": "akabane-marumasuya",            // 英小文字・数字・ハイフン。エリア名-店名ローマ字
    "name": "まるます家",
    "name_kana": "まるますや",
    "name_en": "Marumasuya",               // 英語表記（ローマ字可）
    "kind": "senbero",
    "yokocho": null,                       // 横丁内の店なら親横丁の id
    "area": "赤羽",                         // 街の名前
    "ward": "北区",
    "address": "東京都北区赤羽1-17-7",
    "address_detail": null,                // ビル名・階など
    "station": "JR赤羽駅 東口 徒歩3分",
    "hours": "9:00〜21:30（L.O.21:00）",
    "closed": "月曜",
    "budget": "1,500〜2,500円",
    "budget_min": 1500,                    // 数値（円）。不明なら null
    "budget_max": 2500,
    "price_note": "ジャン酎モヒート、鯉のあらい等。朝9時から営業",  // 名物・価格の具体例
    "social": 4,
    "solo": 5,
    "hiru": true,                          // 15時より前から飲める
    "tags": ["朝飲み", "コの字カウンター", "現金のみ"],   // 下の語彙から（なければ自由に追加可）
    "payment": "現金のみ",                  // 例: 現金のみ / カード可 / キャッシュオン / 不明
    "smoking": "禁煙",                      // 禁煙 / 分煙 / 喫煙可 / 不明
    "english": false,                      // 英語メニューや外国人客が多いなど
    "desc": "2〜3文の説明。どんな店か、歴史、雰囲気。",
    "talk": "1〜2文。人と話すコツ・交流の起きやすさ（例: コの字カウンターで隣と自然に会話が始まる）",
    "tips": "1文。入り方・注意点（例: 週末は行列、相席前提）",
    "shops": null,                         // 横丁なら店舗数の目安（数値）
    "since": "1950年創業",                  // 創業・成立年があれば
    "status": "open",                      // open / closed / uncertain
    "checked": "2025年の口コミで営業確認",     // 何で営業確認したか
    "sources": ["https://...", "https://..."]  // 実際に参照したURL（1〜3件）
  }
]
```
