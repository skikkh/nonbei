# 立ち飲みの店の紹介文を書く（食べログ・ホットペッパー掲載の立ち飲み）

東京の飲み屋地図に、立ち飲みを漏れなく載せる。営業中かどうか・住所・営業時間・予算は別の工程で確認・取得済み。
`IN`（JSON 配列）の各店について、`name`（店名）、`cat`（食べログの分類）、`pr`（店の宣伝文や検索結果の文。英語の機械翻訳のこともある）、
`reviews`（口コミの抜粋。英語の機械翻訳、各100字ほど）だけを根拠に、次の項目を日本語で書いて `OUT` に書き出す。

| キー | 内容 |
|---|---|
| `catch` | 見出し（全角10〜22字、体言止め）。根拠が薄ければ「新橋駅前の立ち飲み」のように場所と業態だけ |
| `desc` | 1〜2文。業態・名物・雰囲気など、根拠のあることだけ。分からなければ「〇〇の立ち飲み。」程度に短く |
| `talk` | 1文。立ち飲みで隣と話しやすい・店主と話せる など、根拠がある場合だけ。無ければ null |
| `social` | 話しやすさ 1〜5（立ち飲みは基本4。口コミに会話・常連・店主の話があれば5、騒がしい・チェーンで回転重視なら3） |
| `solo` | 一人で入りやすさ 1〜5（基本4） |
| `tags` | 当てはまるもの: 朝飲み, 昼飲み, 深夜, 一人飲み歓迎, 常連と話せる, 店主と話せる, 現金のみ, キャッシュオン, チャージなし, 喫煙可, 日本酒, ホッピー, 焼きとん, もつ焼き, 焼き鳥, 串カツ, 刺身, おでん, 煮込み, クラフトビール, レモンサワー, ワイン |
| `kind` | `tachinomi`（立ち飲み）か `kakuuchi`（酒屋の角打ち）。座って飲む店だと分かれば `senbero` |

- 推測で書かない。口コミの英語は意味をくんで自然な日本語に（"Hoppy" → ホッピー、"motsu" → もつ）。
- 常体（〜だ・〜する）か体言止め。

出力（UTF-8 JSON。キーは id）:
```json
{"tl-13018906": {"catch": "…", "desc": "…", "talk": null, "social": 4, "solo": 4, "tags": ["昼飲み"], "kind": "tachinomi"}}
```
25件ごとに OUT を書き出す。補助スクリプトを作るなら scratchpad に、バッチ番号を付けた名前で置く（他の作業と名前がぶつからないように）。最後に件数だけ1行で報告する。
