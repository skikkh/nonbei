# 横丁の所属店から抽出した調査候補

2026年10月27日、既存の地図データから、営業中と記録された横丁154か所の所属店名992件を地域別に抽出した。所属店として記載された名前を調査の入口とするもので、現在の営業、飲み屋としての適合性、住所、位置、横丁への所属を店舗ごとに確認した一覧ではない。候補には重複、閉店、別業態、地図に別名で掲載済みの店が含まれうる。各候補の情報源は親の横丁から引き継いだ参考情報で、掲載先が個々の店について言及しているとは限らない。

抽出時点の名前と地区の照合では、候補一致・要確認94件、一致未確認898件。一致未確認は、対象とする名前と地区がそのまま一致しなかった件数であり、未掲載店舗数ではない。再照合例：

```sh
python3 scripts/check_candidates.py research/候補/横丁の所属店/多摩.json
```

個別に住所・店舗の固有情報・最近の営業証拠・業態を確認し、別表記や近隣地区も含めて地図と重複照合したうえで登録する。確証がない候補は候補として残す。東京全域の全店舗を調査済みとするものではない。
